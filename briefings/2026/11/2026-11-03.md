# Daily Loop-Model Briefing - 2026-11-03

## Outcome

Three papers were added. Library of Layers generalizes a looped core into a routed library
of shared blocks that the model can reuse in any order. Solv3R brings a stationary looped
block to multi-view 3D reconstruction. The third paper is an evaluation of adaptive halting
on Ouro. Library of Layers cites Benhao Huang's *Towards Looped Models Done Right, Part I*:
it follows that analysis in choosing Huginn as its looped baseline, and also cites it in
related work and when discussing loss versus downstream accuracy.

## Added

### Library of Layers (LoL): Adaptively Ordering Transformer Layers at Runtime
[arXiv:2611.03526](https://arxiv.org/abs/2611.03526) · Code: [github.com/arahmani1/library-of-layers](https://github.com/arahmani1/library-of-layers)

**TL;DR:** Instead of a fixed layer order, a small learned router picks which block from a
shared library to run at each depth, so blocks can be repeated or skipped. LoL is competitive
with looped, dense and mixture-of-experts models.

- **Setup:** Models of 360M (GPT-2 Medium shape) and 1B (Llama-3.2-1B shape) parameters,
  trained from scratch on FineWeb, multilingual FineWeb-2, and Nemotron-CC-Math plus
  OpenMath. There are also synthetic sudoku and maze tasks with several solution strategies.
- **Mechanism / Method:** A fixed prelude and coda surround a routed core. At each routed
  depth, a top-1 linear router trained end to end picks one block from the library for each
  window of tokens. A small library forces blocks to be reused, and a large one makes the
  model sparse. FiLM adds depth-dependent modulation, and the core is grown deeper during
  training.
- **Results:** At 1B on math data, after about 90 ExaFLOPs, LoL scores 50.3 on ARC-E, 29.1 on
  ARC-C, 31.2 on HellaSwag, 59.7 on PIQA and 27.9 on GSM8K. The FLOPs-matched sliding-window
  dense model scores 49.5, 28.5, 31.3, 58.8 and 27.5, all within 2 standard errors. With
  library size matched to Huginn's recurrent block at 360M, LoL's loss is competitive. A
  matched MoE reaches a slightly lower training loss (2.75 vs 2.8). Forcing a strategy's
  routing path makes the model use that sudoku or maze strategy almost 100% of the time.
- **Caveat:** LoL matches its baselines but does not beat them. It varies more across seeds,
  is tested only up to 1B parameters on modest token budgets, routes per window rather than
  per token, and does not test extrapolation to greater depth.
- **Why added:** Shared learned blocks can be applied several times within one forward pass,
  which generalizes a looped core to routed reuse.
- **Cites Benhao's work:** *Towards Looped Models Done Right, Part I* (Huang et al.,
  arXiv:2610.23036). The paper follows that analysis in using Huginn as its looped baseline,
  and also cites it in related work and when arguing that higher loss can coexist with strong
  downstream accuracy.

### Solv3R: 3D Looped Transformer as a Multi-view Solver
[arXiv:2611.02857](https://arxiv.org/abs/2611.02857) · Code: release announced on the [project page](https://ubc-vision.github.io/solv3r/)

**TL;DR:** A single transformer block, fully shared across iterations and independent of the
iteration index, keeps refining a multi-view geometry state. Reconstructions can therefore
be continued, extended with new views, or stopped once they converge.

- **Setup:** A 117M-parameter model fine-tuned from DéjàView, a step-conditioned looped 3D
  transformer, on about 25 datasets. It is evaluated on offline reconstruction (DTU, ETH3D,
  7-Scenes, ScanNet++, nuScenes), incremental reconstruction, relocalization and streaming
  benchmarks.
- **Mechanism / Method:** A frozen image encoder feeds one shared block with frame-wise and
  global attention, which is applied repeatedly with input injection, RMS state normalization
  and learned constant gates. Training runs 16-40 calls without gradients, then 8
  differentiable calls supervised at the last one. At inference it runs either 16 calls or
  until the relative state update falls below a threshold, with at most 64 calls.
- **Results:** Adaptive stopping raises DTU camera AUC@3 from 83.3 (DéjàView) and 84.5 (16
  fixed calls) to 85.5, using 3-4 more calls on average. Of 148 windows, 144 converge within
  64 calls, after 17.5 calls on average. Relocalization 5cm/5° recall is 72.8 on 7-Scenes and
  24.9 on Cambridge with a 2.86 MB per-view cache, against 0.0 for DéjàView with a single
  cache. Removing input injection, state normalization or the random pre-calls makes
  accuracy collapse by 1024 calls.
- **Caveat:** The model depends on, and is distilled from, a pretrained DéjàView. It can
  stop at a poor solution when views overlap little. It has no controlled comparison against
  untied models at matched parameters or compute.
- **Why added:** One learned, weight-tied block is iterated within a single inference and
  trained through the unrolled loop, toward a fixed-point-like solver.

### When Does Adaptive Halting Win? Selection Rules Matter in Looped Language Models
[arXiv:2611.02333](https://arxiv.org/abs/2611.02333) · Code: [github.com/lonewolf15116/lookahead-halting](https://github.com/lonewolf15116/lookahead-halting)

**TL;DR:** Whether a trained halting probe beats Ouro's own exit gate depends on the rule used
to choose each method's operating point.

- **Setup:** Frozen Ouro-1.4B with four loops, multiple-choice scoring and one stop decision
  per question. The development set has 20,250 questions and a sealed test set has 8,517
  (OpenBookQA, CommonsenseQA, HellaSwag), with PIQA and Social IQa as out-of-distribution
  checks. The confirmatory study was pre-registered.
- **Mechanism / Method:** A logistic "stability probe" on the loop trajectory is compared with
  Ouro's native exit gate, adapted to one decision per question, and with seven untrained
  readouts. Each method gets an operating point under either a point-only rule (at most 1 pp
  accuracy loss) or a bootstrap-screened rule (the 95% upper bound must also be at most 1 pp).
- **Results:** Under the bootstrap-screened rule, the probe saves more of the loop budget than
  the native gate (macro saving 0.239 vs 0.186, a difference of +0.053 with 95% CI
  [+0.049, +0.057]; +0.038 after the probe's own cost). Under the point-only rule the
  preference reverses (-0.022). The probe shows no clear advantage over an untrained KL
  readout. On Social IQa it loses 3.26 pp (43.32% to 40.05%).
- **Caveat:** The study covers one model, one size, four loops and multiple-choice tasks only.
  Savings are simulated from stored full-depth traces, not measured wall-clock time.
- **Why added:** It evaluates adaptive halting over the reused layer stack of a looped
  language model.

## Near misses

- **Iterated Narrow Networks** ([2611.02840](https://arxiv.org/abs/2611.02840)): proves that
  iterating one fixed width-4 ReLU network, i.e. a weight-tied network, is Turing complete and
  hard to verify. The weights are hand-built rather than learned, and the paper is framed
  around verification rather than looped models.
- **MetaPOCS** ([2611.02478](https://arxiv.org/abs/2611.02478)): a multi-exit unfolded network
  for seismic interpolation whose eight stages have their own weights, so no block is reused.
- **Quantizing Recurrent Language Models Is Easier Than You Think**
  ([2611.01864](https://arxiv.org/abs/2611.01864)): about linear-recurrence sequence mixers,
  which carry a state across tokens rather than reusing layers over depth.
