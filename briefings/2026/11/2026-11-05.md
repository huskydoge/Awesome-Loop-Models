# Daily Loop-Model Briefing - 2026-11-05

## Outcome

Two papers were added. LooM moves the loop into the reader layers of a causal
encoder-decoder so that extra loops cost compute but no cache, and *Loop Before You Leap*
tests recurrent depth in the data-limited BabyLM setting. LooM cites Benhao Huang's
*Towards Looped Models Done Right, Part II* in its related work, as concurrent work on
sharing or compressing the per-loop KV cache of looped models.

## Added

### LooM: Loop-Invariant Memory for Causal Encoder-Decoder Language Models
[arXiv:2611.06835](https://arxiv.org/abs/2611.06835)

**TL;DR:** Loops each decoder reader layer independently and writes a token's local KV entry
only on the first visit, so one checkpoint covers 3-21 layer calls per token at a fixed cache
size and beats a single-pass model once it runs 11 or more calls.

- **Setup:** A 204M-parameter causal encoder-decoder with six encoder and six decoder layers,
  following the DeepSeek-V4.1-Flash layout with dense FFNs, trained from scratch on 5B
  FineWeb-Edu tokens; all runs match parameters and data but not training compute.
- **Mechanism / Method:** The encoder and the first decoder layer write a global memory once
  per token. Decoder layers 2-6 each run zero to four times in a row with shared weights; every
  visit re-reads the global memory and updates the hidden state, but only the first visit
  publishes the token's local KV entry. Random-Depth training samples a budget and then a
  per-layer path, and inference uses one static path per budget chosen on validation data, with
  no router.
- **Results:** At 21 calls, test cross-entropy is 3.0307 against 3.0506 for the six-call
  single-pass model (0.020 nats) and the six-task zero-shot average is 40.94 against 40.15, with
  the same 364.1 KiB cache after a 128-token prompt. Random-Depth at 11 calls matches a model
  trained only at 21 calls (3.0465), cutting decode latency by 33.3%. Rebuilding memory inside
  the loop grows the cache 1.58-1.88x without improving cross-entropy, and after a 64K
  continuation RULER retrieval accuracy is 67.33% against 61.33% for the single-pass model.
- **Caveat:** One 204M backbone, 5B tokens and one seed; gains are small, the looped runs used
  2.9-4.7x the single-pass GPU-hours, and no untied model is given the FLOPs of a 21-call path.
  Below 11 calls the multi-budget model trails the single-pass model.
- **Why added:** Decoder layers are reused with tied weights within one forward pass, and the
  paper's contribution is a cache rule and depth schedule for that loop.
- **Cites Benhao's work:** *Towards Looped Models Done Right, Part II: Rethinking at Fixed
  Points* (Huang et al., arXiv:2610.06833), cited in related work among concurrent methods that
  train a looped stack to tolerate a shared cache or compress the per-loop caches.

### Loop Before You Leap: What Recurrent Depth Can and Cannot Buy in Data-Limited Pretraining
[arXiv:2611.06206](https://arxiv.org/abs/2611.06206)

**TL;DR:** Under a 100M-word budget, a looped Transformer beats a compute-matched 48-layer
model on BLiMP, but recurrence does not reduce the accuracy drop caused by multimodal training.

- **Setup:** BabyLM-style pretraining with a 100M-word budget and three seeds per main
  condition, text-only and multimodal; each image is one frozen DINOv2 feature vector used as a
  prefix token, and caption words count toward the budget. The comparison with deeper standard
  models was pre-registered.
- **Mechanism / Method:** A 12-layer decoder-only core is applied four times with shared
  weights, adding the text embeddings back after every application (input injection). It is
  compared with a 12-layer standard model (matched parameters) and 24- and 48-layer standard
  models (the 48-layer one matches inference compute).
- **Results:** Text-only BLiMP is 76.16 for the looped model against 75.21 for the 12-layer
  model, a difference that is not significant with three seeds. The looped model beats the
  48-layer model by 5.36 points in text-only training and 3.67 in multimodal training, while
  deeper standard models reach lower training loss but lower BLiMP. Multimodal training lowers
  BLiMP by 3.84 points for the standard model and 3.86 for the looped one; a no-image control
  for the loop scores 5.71 points below text-only, pointing to the changed language data.
- **Caveat:** Small models, three seeds and one grammar benchmark as the main measure; the gain
  over deeper models may reflect overfitting of large untied models on 100M words rather than a
  benefit specific to looping. The arXiv comments report acceptance to the BabyLM Challenge 2026.
- **Why added:** A controlled iso-parameter and iso-FLOP study of a weight-tied looped stack,
  including a negative result for the multimodal setting.

## Near misses

- **VITAL: Learning When to Think Aloud in Latent Reasoning**
  ([2611.06108](https://arxiv.org/abs/2611.06108)): a hybrid latent chain of thought that feeds
  the last hidden state back as the next input; the whole model is rerun per step, with no reused
  internal block.
- **DESRec: Deliberate Latent Reasoning for Sequential Recommendation**
  ([2611.06521](https://arxiv.org/abs/2611.06521)): autoregressively appends latent reasoning
  vectors and re-encodes the sequence with the full recommender, which is repeated full-model
  computation rather than layer reuse.
- **SEED: Shallow Encoding Emits Deep Memories**
  ([2611.06084](https://arxiv.org/abs/2611.06084)): compresses recurrent states and shortens
  prefill in hybrid linear-attention models; no layer is applied more than once per token.
- **INOS: Learning Implicit Solves for Dynamic Simulations**
  ([2611.05439](https://arxiv.org/abs/2611.05439)): calls a pretrained neural operator once per
  time step inside a Newmark integrator, an external rollout rather than an internal loop.
