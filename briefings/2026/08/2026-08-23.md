# Daily Loop-Model Briefing - 2026-08-23

## Outcome

One paper was added. Recirculation modifies a frozen Transformer at inference
time so that deep-layer representations can feed back into shallower layers and
receive another traversal through the same learned stack.

## Added

### Recirculation (`2608.17981`)

Recirculation targets state tracking in feedforward Transformers. At each input
step, it mixes a normalized activation from a deep source layer with the
corresponding shallow destination representation, then continues computation
through the same model layers. The reported experiments use one additional
iteration of the Transformer stack.

Why it was added: the recurrent connection returns internal continuous
activations to an earlier layer and explicitly reuses the same learned
Transformer stack within the unrolled computation. This is internal learned
module reuse, not a prompt loop or a second independent model call.

Reader takeaway: the method is training-free for the base model and trades
serial prefill processing for better state tracking. On Gemma 3, the adaptive
variant reports a 23% perplexity reduction across its evaluation suite and a 21%
relative accuracy improvement on GSM8K. Generation latency is essentially
unchanged after prefill, but the sequential prefill requirement is a real cost.
