# Daily Loop-Model Briefing - 2026-08-11

## Outcome

Four recent papers were added. **Depth-adaptive Inference of Looped Language
Models via Continuous Depth Batching** is a serving algorithm for variable-depth
looped LMs. **BDH-CQ** applies recurrent latent reasoning to ARC-style
in-context learning. **ReLIT** proposes a lightweight recursive latent block on
top of a frozen language-model backbone. **Full-bandwidth Transformer** returns
the previous top-layer hidden state to the bottom of the same stack, creating a
learned full-state feedback path across decoding steps.

## Added

### Continuous Depth Batching (`2608.09444`)

Looped language models can spend different numbers of loop iterations on
different tokens, but that breaks ordinary token-level batching. This paper
introduces continuous depth batching, which schedules individual loop
iterations, boundary stages, and one-step-ahead exit decisions separately.

Why it was added: the paper is explicitly about looped LMs where a shared layer
block is iterated a variable number of times within inference. The contribution
is therefore a direct loop-model inference algorithm rather than a generic
serving optimization.

Reader takeaway: on Ouro 1.4B and Huginn 3.5B, the abstract reports up to 99%
of the theoretical adaptive-depth speed-up, with 1.5--1.9x higher offline
throughput and 45--90% lower normalized latency under dynamic serving load.

### BDH-CQ (`2608.09888`)

BDH-CQ combines in-context learning with recurrent latent reasoning. Its
inference-time demonstrations update recurrent memory, and the query is solved
through iterative computation in latent space rather than by verbalizing a
chain of thought.

Why it was added: the abstract makes recurrent memory and iterative latent
computation central to the model's reasoning process. This is an applications
entry because the main reported result is cost-efficient ARC-AGI-1 performance,
not a fully isolated architecture study.

Reader takeaway: the abstract reports that a 150M-parameter configuration
reaches 29.5% pass@2 at a computed inference cost of $0.0007 per task. The
scope evidence is abstract-level: the recurrent latent process is clear, while
the exact reused learned operator should be checked in the full paper if later
auditing needs finer mechanism claims.

### ReLIT (`2608.08113`)

ReLIT augments a frozen TinyLlama-1.1B backbone with a lightweight trainable
recursive block. That block repeatedly refines a latent thinking state before
the model commits to a final answer.

Why it was added: the recursive block is a learned internal module reused during
the model's latent reasoning process. The paper frames the gain as scaling
reasoning through recurrent depth rather than parameter width.

Reader takeaway: the abstract reports strong parameter efficiency on GLoRE
logical-reasoning tasks, including ProofWriter and RuleTaker, while avoiding
explicit intermediate token generation.

### Full-bandwidth Transformer (`2608.08888`)

Standard autoregressive decoding feeds only the sampled token back into the next
step. Full-bandwidth Transformer instead fuses the previous top-layer hidden
state with that token through a learned gate and sends the result to layer zero.
The same Transformer stack can therefore continue processing non-verbalized
state with a renewed depth traversal.

Why it was added: the recurrent signal is an internally generated learned latent
state, not an external prompt or agent action. It returns from the top to the
bottom of the same learned stack, making latent feedback a central architectural
loop rather than ordinary token-only autoregression.

Reader takeaway: the authors train 1B-parameter models for up to 400B tokens.
After instruction tuning, latent-feedback decoding raises GSM8K pass@1 from
67.9% to 71.0%, while a fused-prefill variant reaches 71.8%; the corresponding
HumanEval pass@3 scores move from 46.5% to 47.2% and 47.6%.

## Near miss

### Maglev (`2608.02870`)

Maglev is a learned recurrent-memory Transformer, but its prior decoder states
enter later token processing as recurrent K/V memory. Unlike Full-bandwidth
Transformer, the state is not explicitly returned from the top to layer zero for
another traversal of the same depth. It is therefore useful adjacent work on
sequence-time memory, but remains outside this collection's recurrent-depth
boundary.
