# Daily Loop-Model Briefing - 2026-09-24

## Outcome

Two papers make looped language models cheaper to run, one proposes a recursive
architecture designed to be easier to interpret, and three apply reused internal
computation to speech synthesis, legal summarization, and simulated morphogenesis.

## Added

### Cheaper inference for looped language models

[FlashLoop](https://arxiv.org/abs/2609.29812) starts from the cost problem of looped
Transformers: every extra loop adds another pass and another set of KV states. The
authors observe that, as recurrence proceeds, state changes concentrate on a few tokens,
attention differences are dominated by a sparse set of keys, and KV residuals between
adjacent loops quantize well. Their training-free framework exploits all three and
reports lossless accuracy with up to 1.64x end-to-end speedup and 6x KV-cache reduction
on Ouro and Huginn models ([code](https://github.com/Superone77/FlashLoop)).

[Attention Routing Stabilizes Early](https://arxiv.org/abs/2609.27373) reaches a related
conclusion from the attention side. In recurrent-depth language models, which pieces of
context each position attends to settle well before the hidden states do. WISE runs
full global attention only in the early steps, then restricts later steps to the working
set found earlier, largely preserving multi-hop QA accuracy and reaching up to 1.76x
attention speedup at 4K context ([code](https://github.com/tbn5pj/WISE_code)).

### A recursive architecture for interpretability

[Stream Recursion Model (SRM)](https://arxiv.org/abs/2609.28809) adapts the Hierarchical
Reasoning Model into several interacting latent streams. Each layer calls shared
per-stream step functions in a fixed repeated pattern (for example ABCABC). The model
matches GPT-2 per parameter, and stream-level analysis shows consistent specialization,
which positions SRM as a testbed for mechanistic interpretability.

### Applications beyond text generation

[Depth through recurrence](https://arxiv.org/abs/2609.29768) holds the number of block
calls fixed at 18 and compares seven ways of reusing weights in a flow-matching
text-to-speech Transformer. Applying each of nine blocks twice in a row stays competitive
with the unshared baseline while using 47.1% fewer parameters. Where the reused blocks
sit also matters, and the gap widens at small sampling budgets.

[LexLattice](https://arxiv.org/abs/2609.27032) lays out a legal act's paragraphs on a 2D
lattice and applies one shared neural-cellular-automaton update eight times before
selecting summary sentences. With only a 1.8M-parameter trainable consolidator on top of
a frozen encoder, it reports state-of-the-art ROUGE across all 24 EUR-Lex-Sum languages.
[On Growth and Form, and Function](https://arxiv.org/abs/2609.29755) adds LoRA adapters
to neural cellular automata that grow shapes from a single cell by repeating one shared
local update. Rank-one adapters are enough to implement horizontal and vertical scaling,
and they transfer zero-shot to other target shapes.

## Near misses

- [Log-Depth Recurrent Language Modeling](https://arxiv.org/abs/2609.28212) reuses a
  tree-composition operator across sequence prefixes, so its recurrence runs over the
  sequence rather than over model depth.
- [Online Task Adaptation via Self-Organisation](https://arxiv.org/abs/2609.29281) uses
  recurrent cellular cells, but its central mechanism is fast-memory updates across the
  incoming data stream, not reuse of the same layers in depth.
- [Anomaly-LR](https://arxiv.org/abs/2609.29457) refines latent visual representations
  step by step, but the abstract does not describe reusing internal learned layers.
