# Daily Loop-Model Briefing - 2026-09-09

## Outcome

Two papers were added. DART targets the training dynamics of recurrent reasoning
models, while CVRR makes shared-layer latent visual computation the required route
to prediction.

## Added

### DART (2609.05988)

DART replaces one-hot supervision with a local target distribution and trains an
input-conditioned critic to align recurrent model outputs with that neighborhood.
The framework applies to both Deep Thinking Systems and Tiny Recursive Models. On
the reported 31x31 Maze setting, final accuracy rises from 73.88 +/- 25.98% with
cross-entropy to 99.91 +/- 0.13%; on 50%-masked Sudoku at depth 42, accuracy rises
from 32.3 +/- 1.7% to 37.5 +/- 0.1%.

Why it belongs: the evaluated reasoning models repeatedly apply a fixed learned
computation block within one forward process, and DART is designed specifically to
shape those recurrent trajectories.

Reader takeaway: DART improves solution quality and retention, but it does not by
itself remove late-iteration collapse on Chess. Progressive DART supplies that
long-horizon stability, reaching 83.52 +/- 0.16% final accuracy versus 11.13 +/-
4.64% for DART alone in the reported 50-iteration comparison.

### CVRR (2609.06746)

CVRR initializes a recurrent question state from a pretrained multimodal model,
then reuses one decoder layer and the same LoRA parameters for four recurrent steps.
Each step re-reads fixed visual rows; before decoding, the original visual rows and
multimodal KV cache are removed, so the final recurrent state is the only
image-conditioned path to the answer.

Why it belongs: the shared decoder layer is explicitly reapplied across latent depth
inside one forward process, with an evolving question state and persistent visual
evidence.

Reader takeaway: under the strict no-bypass interface, CVRR reports 81.2% on V*,
52.7% MMVP pair accuracy, and 55.2% on BLINK. Removing visual re-reading reduces V*
and MMVP pair accuracy by 12.0 and 34.7 points, respectively, supporting the claim
that recurrence uses the persistent evidence rather than merely carrying an initial
visual representation.

## Near miss

- 2609.07874, InfluenceField, uses a shared transition operator for multi-step causal
  field propagation, but the catalog fit depends on treating a task-specific world-model
  rollout as a central loop-model design. That would broaden the current scope beyond
  explicit recurrent-depth models, so it was not added.
