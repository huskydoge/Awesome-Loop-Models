# Daily Loop-Model Briefing - 2026-10-28

## Outcome

No paper was added. Today's arXiv listings had many papers that use the words loop,
recursive or recurrent, but most were agent loops, recursive self-improvement pipelines,
closed-loop control or ordinary recurrent networks. None of the three closest candidates
reuses a learned internal block within one forward pass.

## Added

None today.

## Catalog update

This run checked one fifth of the existing catalog (74 papers) for publication venue,
official code links and community comment links. Two entries gained code links, both taken
from the paper itself and confirmed against the repository's README:

- *i-DEQ: A stable inertial deep equilibrium model for image restoration*
  ([2605.19705](https://arxiv.org/abs/2605.19705)) now links
  [antoninclerc/i-DEQ](https://github.com/antoninclerc/i-DEQ), which its experiments section
  names as the code release.
- *Dissecting Hierarchical Reasoning Models: A Mechanistic Study*
  ([2609.22197](https://arxiv.org/abs/2609.22197)) now links
  [LeoRodrigues05/HRM](https://github.com/LeoRodrigues05/HRM), which the paper's title block
  names as its code repository.

Venues were not changed. Five papers in this group state an acceptance on arXiv that the
catalog does not yet record (ECCV 2026, NeurIPS 2026, EMNLP 2026, a NeurIPS 2026 workshop and
an ICLR 2026 workshop), but no official proceedings or acceptance page could be confirmed
today, so they stay as they are for now.

## Near misses

- **Latent Residual Reasoning for Ranking in Generative Recommendation**
  ([2610.36890](https://arxiv.org/abs/2610.36890)): Refiner refines ranking scores over several
  latent reasoning steps, but each step appends reasoning tokens and runs the whole LoRA-adapted
  transformer again, which is a repeated full-model pass rather than a reused internal block.
- **ADTGuard** ([2610.36574](https://arxiv.org/abs/2610.36574)): a streaming safety guard that
  reads safety signals from different layers of a language model; it chooses which layers to
  observe but does not reuse any of them.
- **An Algebra of Transformers** ([2610.36795](https://arxiv.org/abs/2610.36795)): a formal
  algebra for reasoning about transformer programs, whose recursion operator is a logical
  construct rather than a model that reuses its layers.
