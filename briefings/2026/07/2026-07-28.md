# Daily Loop-Model Briefing - 2026-07-28

## Outcome

One new paper was added today: **Penelope: Localized Latent Recurrence for Efficient Structured Reasoning**. It is a clean designs entry because the abstract describes recurrent computation inside a decoder interval, not an external agent loop or repeated full-model prompting.

## Added

### Penelope: Localized Latent Recurrence for Efficient Structured Reasoning (`2607.25915`)

Penelope adds recurrent latent computation to pretrained decoder-only Transformers without repeatedly running the full decoder. The lower decoder prefix is evaluated once to build a problem-conditioned boundary memory, then that memory is refined through time-modulated GRU dynamics and recurrent readout states before answer generation.

Why it was added: the core mechanism is explicit internal recurrence within one model-side reasoning process. The paper localizes the loop to a narrow decoder interval, which makes it a useful design point between full looped Transformers and token-level chain-of-thought generation.

Reader takeaway: the abstract reports competitive accuracy against established latent-reasoning models on structured-reasoning benchmarks while reducing measured inference latency at validation-selected latent budgets.
